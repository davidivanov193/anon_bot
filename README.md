# Anonymous Messages Bot

Telegram-бот для отправки анонимных сообщений. Каждый пользователь получает персональную ссылку, по которой другие могут отправлять ему анонимные сообщения.

## Установка

1. Клонируйте репозиторий:
```bash
git clone <url>
cd anon_bot
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Создайте файл `.env` по образцу `.env.example`:
```bash
cp .env.example .env
```

4. Заполните `.env`:
   - `BOT_TOKEN` — токен бота от @BotFather
   - `OWNER_ID` — ваш Telegram user ID (можно узнать через @userinfobot)

5. Запустите бота:
```bash
python bot.py
```

## Как работает

- Пользователь запускает бота и получает персональную ссылку
- Другие переходят по ссылке и отправляют анонимное сообщение
- Получатель видит сообщение и может ответить
- Владелец бота видит информацию об отправителе

## Команды

- `/start` — главное меню
- `/stats` — статистика (отправлено/получено сообщений)
